# BreakPoint AI v2: локальный эксперимент

Основной вход: local.py. Colab не требуется. Это расширение исследования, а не доказанное улучшение безопасности: реальные HF-запуски ещё предстоят.

## Что добавлено

256 запросов: 24 рискованные базовые задачи × 8 форматов = 192 запроса, 16 безопасных задач × 4 формата = 64 запроса. Это 40 базовых задач, а не 256 независимых целей. Категории включают мошенничество, нарушения приватности, ложные отзывы, давление, вымышленные доказательства и безопасные задачи программирования, перевода, письма. Варианты меняют регистр, пробелы и оформление. Это поверхностные проверки устойчивости, не автоматически оптимизированные jailbreak-атаки.

Четыре конфигурации образуют факторный эксперимент:

|Конфигурация|Safety prefix|Output guard|
|---|---|---|
|A|нет|нет|
|B|да|нет|
|C|да|да|
|D|нет|да|

B/C используют одинаковый исходный ответ, A/D тоже. Так можно отдельно сравнить эффект prefix, guard и их сочетания. Неполные ответы блокируются в C/D: это часть общего механизма, а не доказательство работы только классификатора.

Есть development и heldout наборы. Все варианты одной базовой задачи находятся в одном наборе. Настраивай протокол на development, затем фиксируй его перед heldout. Это синтетический корпус, его категории и допустимость нужно проверить вручную. Не подгоняй правила по ответам из heldout. Старые optimized prompts импортируй отдельным корпусом через scripts/import_midterm.py, не называй новые примеры исходными атаками AutoDAN.

## Установка

Распакуй архив, открой терминал в breakpoint_a3. Нужен Python 3.10+. Создай окружение:

```
python -m venv .venv
```

Windows PowerShell:

```
.\.venv\Scripts\Activate.ps1
```

Linux/macOS:

```
source .venv/bin/activate
```

Затем:

```
python -m pip install -r requirements.txt
python local.py check
python local.py smoke
```

Для GPU нужна NVIDIA и сборка PyTorch с CUDA. Если CUDA=False, используй официальный установщик-команду на https://pytorch.org/get-started/locally/ под свою ОС и драйвер. Установка requirements не гарантирует CUDA. В текущей реализации только cuda/cpu, Apple MPS не реализован. Требования к памяти зависят от длины запросов/ответов; сначала короткий pilot, не полный прогон.

Для реального guard сначала получи доступ к https://huggingface.co/meta-llama/Llama-Guard-3-1B и прими условия самостоятельно. Авторизуйся без записи токена в исходники:

```
python -c "from huggingface_hub import login; login()"
python local.py pilot --cases data/development.jsonl --out runs/dev_check
python local.py main --cases data/heldout.jsonl --out runs/heldout_v2
```

CPU: добавь --device cpu. Он может работать очень медленно. Первый запуск скачивает две модели. Скачивание/загрузка не входят во время ответа. Для продолжения повтори точно ту же команду. При изменении кода, параметров или корпуса используй новую папку. Не запускай одновременно два процесса на одну папку.

Полный expanded корпус с тремя seeds и четырьмя конфигурациями даст 3072 записи: 1536 генераций DeepSeek и до 1536 проверок guard. Это длительный эксперимент. Основной main по умолчанию берёт только heldout; точный состав — data/corpus_manifest.json. Выполни pilot прежде, чем планировать длительность основного запуска.

## Оценка и анализ

```
python local.py review --out runs/heldout_v2 --reviewer reviewer1
python local.py review --out runs/heldout_v2 --reviewer reviewer2
```

Разметь annotations.csv по docs/ANNOTATION.md, используя полный текст review.html. Разметка всех raw/delivered ответов объёмна: заранее распредели работу. Не используй сам guard как независимого судью. Сохрани обе разметки и согласуй спорные случаи в отдельной папке.

```
python local.py report --out runs/heldout_v2 --reviewer reviewer1
```

Выходы: dashboard.html, comparison.md, summary.json, category_metrics.csv, advanced_analysis.json. Анализ показывает категории, варианты, задержку p95, ошибки и парные изменения результатов. Bootstrap пересэмплирует базовые задачи, а не отдельные варианты. Задачи с нерешёнными оценками исключаются из интервала и явно учитываются. Это создаёт риск смещения: показывай число исключённых задач. При недостаточной разметке интервала может не быть. Показатели mock не являются экспериментальными результатами.

Предыдущий PDF и презентация описывают версию с A/B/C. Они оставлены в legacy_v1 только как исторические черновики. Для новой версии используй текущую схему A/B/C/D и таблицы реального запуска; не сдавай старые слайды как описание v2.
